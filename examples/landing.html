Questions

Can I use it with Tailwind?

Yes. Import dist/hardstock.theme.css and write utilities against the tokens.

Is there a dark theme?

One, and it is warm black rather than grey. Set data-hs-theme="night-yellow".

Why no rounded corners at all?

Because a single rounded corner reads as a different language, and the page splits.

Hand it to an agent and get the same page twice.
